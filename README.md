# Panduan Penggunaan EcoRisk

EcoRisk digunakan untuk melaporkan titik rawan sampah, menindaklanjuti laporan, dan mencatat hasil pengelolaan sampah. Buka alamat web EcoRisk yang diberikan oleh pengelola aplikasi.

## Mulai menggunakan aplikasi

- Untuk menggunakan fitur sesuai peran, pilih **Masuk** lalu isi email dan kata sandi.
- Warga yang belum memiliki akun dapat memilih **Daftar sebagai warga**, mengisi data yang diminta, lalu masuk ke aplikasi.
- Akun petugas dan administrator diberikan oleh pengelola. Setelah masuk, aplikasi menampilkan halaman sesuai peran akun.

## Status laporan

Laporan mengikuti alur **Menunggu → Diproses → Selesai**. Petugas memperbarui status ketika penanganan dimulai dan setelah selesai. Laporan yang tidak memiliki titik koordinat tetap dapat dilihat pada daftar, tetapi tidak ditampilkan sebagai titik pada peta.
